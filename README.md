# copilot-gui

`copilot-gui` is a small Java desktop application built with Gradle. It uses Swing and JGoodies Forms to show a simple welcome window with a message and a close button.

## Requirements

- Java 21 or newer
- A terminal

## Run

From the repository root:

```bash
./gradlew run
```

On Windows:

```powershell
gradlew.bat run
```

## Build

```bash
./gradlew build
```

## Project layout

- `src/main/java/com/silvionetto/Main.java` — application entry point
- `build.gradle` — Gradle build and dependencies
